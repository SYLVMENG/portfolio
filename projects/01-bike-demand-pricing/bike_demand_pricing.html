Bike demand forecasting, pricing and capacity planning¶

Bike store: two-week demand forecasting (OLS), price-based choice model (multinomial logistic regression), and a two-stage capacity / price / quantity decision evaluated over a test year (rolling backtest).

Information-set convention used throughout. Period t covers the 14 days starting period_start[t]. A decision taken at the start of period t − k can only use demand of periods that have fully ended (≤ t − k − 1) and transactions dated before that day. Every model used for a decision is re-estimated on exactly that information (expanding window).

Rolling-origin evaluation. Each forecast of period t at horizon h uses a model estimated only on target periods ≤ t − h, so no parameter uses data from after the forecast origin. The model specification is chosen on periods 78–99, the last period completed before the earliest test-year decision (the capacity reservation for period 104 at the start of period 100), and is then frozen; only its parameters are updated. Periods 104–129 are a rolling backtest over the historical test interval. (Earlier drafts of this project looked at test-interval results, so the backtest is not a fully untouched hold-out.)

SPECS = {
    "base":          ["trend", "s1", "c1", "lag_h", "lag_h1", "lag_26"],
    "fourier2":      ["trend", "s1", "c1", "s2", "c2", "lag_26"],
    "fourier2_lags": ["trend", "s1", "c1", "s2", "c2", "lag_h", "lag_h1", "lag_26"],
    "trend_lag26":   ["trend", "lag_26"],
}

def make_features(h, spec):
    t = y.index.to_numpy()
    X = pd.DataFrame(index=y.index)
    X["trend"] = t
    for k in (1, 2):
        X[f"s{k}"] = np.sin(2 * np.pi * k * t / SEASON)
        X[f"c{k}"] = np.cos(2 * np.pi * k * t / SEASON)
    X["lag_h"] = y.shift(h)
    X["lag_h1"] = y.shift(h + 1)
    X["lag_26"] = y.shift(SEASON)
    return sm.add_constant(X[SPECS[spec]])

FEATURES = {(h, s): make_features(h, s) for h in range(1, 7) for s in SPECS}

def fit_ols(h, spec, last_target):
    """OLS for horizon h estimated on target periods <= last_target."""
    X = FEATURES[(h, spec)]
    rows = X.index[(X.index <= last_target) & X.notna().all(axis=1)]
    return sm.OLS(y[rows], X.loc[rows]).fit()

def rolling_forecast(h, spec, t):
    """Forecast of period t issued after period t-h has ended."""
    model = fit_ols(h, spec, t - h)
    return float(model.predict(FEATURES[(h, spec)].loc[[t]]).iloc[0])

def evaluate(spec, targets, h):
    f = np.array([rolling_forecast(h, spec, t) for t in targets])
    return y[targets].to_numpy() - f, f

Question 2 – Logistic regression for bike choice¶

Each transaction is one choice among the three bikes, with the three prices observed at that time. A multinomial logit (base: Comfort Mountain, prices in $100s) is fitted on all 1,682 transactions. Q2 does not ask for a train/test split, so the full-sample fit answers Q2 and is descriptive only. The same model fitted only on transactions before the first Q3 decision (8 Dec 2024) is shown next to it; all Q3 decisions use logit models estimated only from information available before each decision.

CHOICE_CODE = {p: i for i, p in enumerate(PRODUCTS)}

def fit_choice_model(data, weight_by_quantity=False):
    if weight_by_quantity:  # integer frequency weights via row replication (point estimates only)
        data = data.loc[data.index.repeat(data["quantity"])]
    X = sm.add_constant(data[PRICE_COLS] / 100)
    return sm.MNLogit(data["Product"].map(CHOICE_CODE), X).fit(disp=False)

def choice_probs(model, prices):
    prices = np.atleast_2d(np.asarray(prices, dtype=float))
    X = np.column_stack([np.ones(len(prices)), prices / 100])
    return np.asarray(model.predict(X))

Unit of analysis. The logit models transactions, while the OLS model forecasts bikes (1,682 transactions, 2,051 bikes; 286 transactions contain more than one bike). Using D̂ × P(choice) assumes transaction shares equal bike shares. The checks below compare the two shares and refit the logit with the log-likelihood weighted by quantity. Only point predictions are compared: replicated rows are not independent choices, so the default standard errors of the weighted fit are not used for inference.

Rolling out-of-sample check. For each test-interval period t, the logit is re-estimated on transactions dated before the pricing decision (start of t − 1) and used to predict the choices actually made in period t at the prices actually charged. The benchmark predicts every choice with the historical product shares available at the same date. This measures predictive ability under historical prices, not the causal effect of changing prices.

Question 3 – Two-stage capacity, price and quantity decisions¶

Timeline and information sets¶

Four two-week periods (56 days) approximate "two months". A decision at the start of period t − k can use demand of periods ≤ t − k − 1 and transactions dated before that day.

stage when latest complete demand demand forecast
1. reserve shared capacity K start of t − 4 y(t − 5) OLS with lags ≥ 5 (D̂₅)
2. set prices p and integer order quantities q start of t − 1 y(t − 2) OLS with lags ≥ 2 (D̂₂)

Every forecast, forecast-error sample, logit model and price range used for a decision is computed only from information available on that decision date.

Contract and costs (assumptions for this experiment, not supplier quotes)¶

  • Unit purchase cost cⱼ = 65% of the Q2 reference price ($2,730 / $1,267.50 / $325), fixed regardless of the retail price chosen.
  • Reserving K units costs a deposit of $100 per unit, paid at stage 1. Each bike ordered at stage 2 uses one unit and the $100 is credited against its purchase cost; unused deposits are forfeited. Capacity is valid only for its own two-week period.
  • Unsold bikes are disposed of at the end of the period at a net salvage value sⱼ = 50% of cost (scenario value); there is no carry-over.

Profit of one period: Π = Σⱼ [ pⱼ·min(qⱼ, Dⱼ) + sⱼ·(qⱼ − Dⱼ)⁺ − (cⱼ − 100)·qⱼ ] − 100·K, with Σⱼ qⱼ ≤ K.

Demand uncertainty¶

  • Total demand. D = round(max(D̂₂ + e, 0)), where e is drawn from the rolling-origin lag-2 forecast errors of earlier periods (each error comes from a model estimated only on data before its own forecast origin), not from in-sample residuals.
  • Forecast update between the stages. At stage 1, D̂₂ is not yet known. It is simulated as D̂₅ + u, with u the historical gap between the rolling lag-2 and lag-5 forecasts of the same period. Then D = D̂₅ + u + e, so the 8-week error (u + e) and the 2-week error (e) are correlated through e; u and e are treated as independent (checked below).
  • Split across bikes. Given D, (D_CM, D_TT, D_UM) | D ~ Multinomial(D; P_CM, P_TT, P_UM) with the logit probabilities, so the three demands always add up to D. Each bike's marginal demand is Binomial(D, Pⱼ(p)); the expected profit is a sum over bikes, so only these marginals are needed to compute the expected marginal order values. This assumes that transaction choice shares apply to individual bikes and that bikes choose independently. In the data a multi-bike transaction always contains one model, so this understates the variance of each bike's demand (E[q²]/E[q] = 1.44 bikes per transaction).

Optimization¶

  • Stage 2. For fixed prices, the expected value of the (k)-th unit of bike j is (pⱼ − sⱼ)·P(Dⱼ ≥ k) + sⱼ − (cⱼ − 100), which decreases in k. Units are added one at a time to the bike with the highest positive marginal value until K is used or no marginal value is positive; this gives the optimal integer quantities for those prices. Prices (whole dollars, between the 5th percentile and the cap percentile of past prices) are searched on a coarse-then-fine grid: a numerical candidate within the search range, not a proof of global optimality.
  • Stage 1. K* = argmax_K { E[V₂(K) | info at t − 4] − 100·K }, where V₂ is the stage-2 optimal expected value: for each simulated D̂₂ the prices and quantities are re-optimized against the remaining uncertainty e, never against a realized demand. Stage 1 searches 11 whole-dollar prices per bike; the reported K is optimal on that discrete grid (a grid-convergence check follows the results).
  • Approximation. The capacity stage simulates only the update of the demand forecast; it keeps the logit model, price bounds and error distribution at their values on the reservation date. The pricing stage re-estimates them with the newer data. K is therefore optimal for this approximate model, not for a full dynamic model of future learning.

# P(Binomial(d, p) >= k) for k = 1..K_MAX, d = 0..D_MAX, p on a fine grid (computed once)
P_AXIS = np.linspace(0, 1, N_PGRID)
_k = np.arange(1, K_MAX + 1)[None, :, None]
_d = np.arange(D_MAX + 1)[None, None, :]
_p = P_AXIS[:, None, None]
with np.errstate(all="ignore"):
    SF = np.where(_k <= _d, betainc(_k, np.maximum(_d - _k + 1, 1), _p), 0.0)   # (P, K, D)

def demand_pmf(centres, e):
    """pmf of total demand for each centre (D̂), using error sample e -> (n_centres, D_MAX+1)."""
    d = np.clip(np.round(np.maximum(np.asarray(centres)[:, None] + e[None, :], 0)), 0, D_MAX).astype(int)
    pmf = np.zeros((len(d), D_MAX + 1))
    for i, row in enumerate(d):
        pmf[i] = np.bincount(row, minlength=D_MAX + 1) / len(row)
    return pmf

def tail_table(pmf):
    """T[c, p, k] = P(D_j >= k) when each bike picks j with probability P_AXIS[p]."""
    return (pmf @ SF.reshape(-1, D_MAX + 1).T).reshape(len(pmf), N_PGRID, K_MAX)

def tails_at(T, probs):
    """Interpolate tail table at choice probabilities probs (G,3) -> (C, G, 3, K)."""
    x = probs * (N_PGRID - 1)
    i0 = np.clip(np.floor(x).astype(int), 0, N_PGRID - 2)
    w = (x - i0)[None, :, :, None]
    return T[:, i0, :] * (1 - w) + T[:, i0 + 1, :] * w

def unit_costs(cfg):
    c = cfg["cost_ratio"] * REF_PRICE
    return c, cfg["salvage_ratio"] * c

def marginals(prices, tails, cfg):
    """Expected value of each additional unit -> (C, G, 3, K)."""
    c, s = unit_costs(cfg)
    return ((prices - s)[None, :, :, None] * tails
            + (s - (c - cfg["deposit"]))[None, None, :, None])

def value_curve(marg):
    """Best value using at most K units, K = 0..K_MAX -> (C, G, K_MAX+1)."""
    C, G = marg.shape[:2]
    m = -np.sort(-marg.reshape(C, G, -1), axis=2)[:, :, :K_MAX]
    return np.concatenate([np.zeros((C, G, 1)), np.cumsum(np.maximum(m, 0), axis=2)], axis=2)

def price_grid(lo, hi, n):
    # whole-dollar prices that stay inside the continuous bounds
    g = [np.unique(np.round(np.linspace(np.ceil(l), np.floor(h), n))) for l, h in zip(lo, hi)]
    return np.array(np.meshgrid(*g)).reshape(3, -1).T

def stage1(t, cfg, parity=None, grid_n=11):
    tb = tables_for(t, parity, cfg.get("fixed_params", False))
    logit = logit_at(info_period(t - 4, cfg), cfg["logit"])
    lo, hi = bounds_at(info_period(t - 4, cfg), cfg["cap_q"])
    P = np.atleast_2d(cfg["fixed_prices"]) if cfg["fixed_prices"] is not None else price_grid(lo, hi, grid_n)
    best = None                                         # (U, K+1): best prices per simulated D̂2
    for chunk in np.array_split(P, max(1, len(P) // 150)):
        V = value_curve(marginals(chunk, tails_at(tb["T_res"], choice_probs(logit, chunk)), cfg)).max(axis=1)
        best = V if best is None else np.maximum(best, V)
    EV = best.mean(axis=0)
    profit = EV - cfg["deposit"] * np.arange(K_MAX + 1)
    return int(np.argmax(profit)), EV

def stage2_search(K, P, T, logit, cfg):
    marg = marginals(P, tails_at(T, choice_probs(logit, P)), cfg)[0]       # (G, 3, K_MAX)
    flat = marg.reshape(len(P), -1)
    order = np.argsort(-flat, axis=1)
    top = np.take_along_axis(flat, order[:, :K], axis=1)
    value = np.maximum(top, 0).sum(axis=1)
    i = int(np.argmax(value))
    used = order[i, :K][top[i] > 0]
    q = np.bincount(used // K_MAX, minlength=3)
    # capacity binds if all K units are used and one more unit would still add value
    binding = bool(q.sum() == K and K < flat.shape[1] and flat[i, order[i, K]] > 0)
    return value[i], P[i], q, binding

def stage2(t, K, cfg, parity=None):
    tb = tables_for(t, parity, cfg.get("fixed_params", False))
    logit = logit_at(info_period(t - 1, cfg), cfg["logit"])
    lo, hi = bounds_at(info_period(t - 1, cfg), cfg["cap_q"])
    if cfg["fixed_prices"] is not None:
        return stage2_search(K, np.atleast_2d(cfg["fixed_prices"]), tb["T_pr"], logit, cfg) + ((lo, hi),)
    v, p, q, _ = stage2_search(K, price_grid(lo, hi, 13), tb["T_pr"], logit, cfg)
    step = (hi - lo) / 12
    v, p, q, b = stage2_search(K, price_grid(np.maximum(p - step, lo), np.minimum(p + step, hi), 9),
                               tb["T_pr"], logit, cfg)
    return v, p, q, b, (lo, hi)

def evaluate_plan(t, K, p, q, cfg, parity=None, logit_kind=None):
    """Expected outcome of fixed (K, p, q) under the stage-2 demand distribution."""
    tb = tables_for(t, parity, cfg.get("fixed_params", False))
    logit = logit_at(info_period(t - 1, cfg), logit_kind or cfg["logit"])
    c, s = unit_costs(cfg)
    tails = tails_at(tb["T_pr"], choice_probs(logit, p))[0, 0]             # (3, K_MAX)
    sales = np.array([tails[j, :q[j]].sum() for j in range(3)])           # E[min(q, D)]
    unsold = q - sales
    out = dict(exp_sales=sales.sum(), exp_unsold=unsold.sum(),
               revenue=float(p @ sales), salvage=float(s @ unsold),
               purchase_cost=float(c @ q), forfeited_deposit=cfg["deposit"] * (K - q.sum()))
    out["profit"] = out["revenue"] + out["salvage"] - out["purchase_cost"] - out["forfeited_deposit"]
    return out

def run_policy(cfg, parity=None, label=""):
    rows = []
    for t in test_idx:
        K, _ = stage1(t, cfg, parity)
        v, p, q, binding, (lo, hi) = stage2(t, K, cfg, parity)
        if cfg["fixed_prices"] is None:
            assert np.all(p >= lo) and np.all(p <= hi), "price outside allowed range"
        ev = evaluate_plan(t, K, p, q, cfg, parity)
        assert abs(ev["profit"] - (v - cfg["deposit"] * K)) < 1e-6 * max(1, abs(v))
        rows.append({"period": t, "period_start": period_start[t].date(),
                     "forecast_lag5": tables_for(t, parity, cfg.get("fixed_params", False))["d5"],
                     "capacity_K": K,
                     "forecast_lag2": tables_for(t, parity, cfg.get("fixed_params", False))["d2"],
                     **{f"price_{s_}": p[j] for j, s_ in enumerate(SHORT)},
                     **{f"qty_{s_}": int(q[j]) for j, s_ in enumerate(SHORT)},
                     "unused_capacity": K - int(q.sum()),
                     "capacity_binding": binding,
                     **{f"at_cap_{s_}": bool(p[j] >= np.floor(hi[j])) for j, s_ in enumerate(SHORT)},
                     **ev, "historical_demand": int(y[t])})
    return pd.DataFrame(rows)

Estimation check: rolling vs fixed parameters. The brief asks for model parameters estimated on the training data. The main results re-estimate the OLS models, the logit, the price bounds and the error sample at every decision date, using only data observed before that date, as a manager would. As a check, the fixed-parameter variant estimates all of them once on data before the first decision (8 Dec 2024) and keeps them for the whole test year; the test-year demand then enters only as the observed lags in the forecasts. Each variant's profit is an expectation under its own demand model, so the two profit levels are not a test of which variant is better.

Error-sample sensitivity. The expectations above use the same error sample for optimizing and evaluating. Here the rolling errors are split by period parity: each policy is optimized with one half and evaluated with the other, in both directions. The two halves have different mean errors, so a change in profit mixes sampling variation, a shift in the error distribution and overfitting. The regret compares, under the same evaluation distribution, the plan built on the other half with the plan built on the evaluation half. It measures how sensitive the policy is to the error sample; it is not an independent estimate of overfitting loss (the reference plan is itself an approximate two-stage solution), nor a market validation.

def stage1_dense(t, cfg, n_cm=61, n_other=11):
    tb = tables_for(t)
    logit = logit_at(t - 4, cfg["logit"])
    lo, hi = bounds_at(t - 4, cfg["cap_q"])
    axes = [np.unique(np.round(np.linspace(np.ceil(l), np.floor(h), n)))
            for l, h, n in zip(lo, hi, (n_cm, n_other, n_other))]
    P = np.array(np.meshgrid(*axes)).reshape(3, -1).T
    best = None
    for chunk in np.array_split(P, max(1, len(P) // 150)):
        V = value_curve(marginals(chunk, tails_at(tb["T_res"], choice_probs(logit, chunk)), cfg)).max(axis=1)
        best = V if best is None else np.maximum(best, V)
    o = best.mean(axis=0) - cfg["deposit"] * np.arange(K_MAX + 1)
    return int(np.argmax(o)), o

Reading the numbers. All revenues and profits are model expectations under the stated assumptions, not verified business results. The historical demand of the test year occurred at historical prices, so it is shown only as a reference. Total demand does not respond to the overall price level, there is no no-purchase option, and two bikes sit at their price caps; these make the profit gain over the fixed-price policy optimistic. Customers who find their bike out of stock are assumed not to switch to another model; for a given plan this understates expected sales and profit, but its effect on the optimal capacity, prices and quantities is not signed. The practical recommendation is to validate substitution between models and price sensitivity (for example with controlled price tests) before acting on these prices.
