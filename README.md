# Yishuang (Sylvia) Meng · Analytics Portfolio

Live site: https://sylvmeng.github.io/portfolio/

Data analytics projects in forecasting, pricing, customer segmentation, cost-to-serve and model validation.
Each folder has a write-up of the problem, approach and results with key figures. Most also include the code, the Jupyter notebook and a rendered HTML version you can read in the browser.

| Project | What it shows | Tools |
|---|---|---|
| [Bike demand forecasting, pricing and capacity planning](projects/01-bike-demand-pricing) | Rolling-origin forecasting, choice modelling, two-stage optimization without look-ahead | Python, statsmodels, scikit-learn |
| [Credit card customer segmentation](projects/02-credit-card-segmentation) | Feature engineering, comparing four clustering methods, stability checks | Python, scikit-learn |
| [Cost-to-serve customer profitability](projects/03-cost-to-serve) | Activity-based cost allocation, break-even order size, BI dashboard (team project) | Excel, Power Query, VBA, Power BI |
| [Can a forecast time tech vs retail?](projects/05-tech-retail-long-short) | Time-series model selection, a backtest without look-ahead, testing whether a result is luck | Python, statsmodels |
| [Leakage-safe model tuning and PCA trade-offs](projects/04-model-tuning-leakage-pca) | How tuning on the test set overstates accuracy; when PCA helps a regression | Python, scikit-learn |

Datasets provided under course or company terms are not included. Public datasets are linked from each project.
